# Sanhya Birthday Website 🎂

A small cinematic birthday website made with plain HTML, CSS and JavaScript.

## Run it
Open `index.html` in a browser.

## Secret code
`SANHYA`

## Customize
- Change the birthday message in `index.html`
- Replace the two files inside `images/` with other photos if desired
- Change the secret message near the bottom of `index.html`
